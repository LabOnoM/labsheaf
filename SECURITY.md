# Security policy

Please report a security problem in the Labsheaf specification, or in an implementation published from this repository,
privately to **support@nexitia.ai** with "Labsheaf security" in the subject, rather than in a public issue.

Include what you found, how to reproduce it, and what an attacker could achieve. We will acknowledge the report, keep
you informed while we assess it, and credit you in the fix unless you prefer otherwise.
