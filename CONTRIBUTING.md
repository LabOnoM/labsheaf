# Contributing to Labsheaf

Thank you for helping. Questions, reviews of the specification and proposals are welcome as issues.

## Pull requests

- By contributing, you agree that your contribution is licensed under the MIT licence of this repository (see
  `LICENSE`), the same terms under which it is published.
- Every commit must carry a `Signed-off-by` line certifying the Developer Certificate of Origin 1.1
  (https://developercertificate.org/): that you wrote the change or otherwise have the right to submit it under this
  licence. `git commit -s` adds the line.
- Keep each pull request to one change, explain why it is needed, and update the affected sections of `SPEC.md`.
- Do not include material you are not free to license under MIT, such as text copied from other specifications.

## Security

Report security problems privately as described in `SECURITY.md`, never in a public issue or pull request.
